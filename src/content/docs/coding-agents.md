# Coding agents

For coding agents, use **[SKILL.md](https://github.com/logfoxai/callspec/blob/main/skills/callspec/SKILL.md)** — short invariants for Callspec work. Topic guides are linked from the [README Contents](https://github.com/logfoxai/callspec#contents).

Copy that file into `.cursor/skills/callspec/SKILL.md` (or your agent’s skills folder) when you want agents to follow Callspec conventions.

Human walkthrough: [Getting started](./getting-started.md).
